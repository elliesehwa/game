cPanel에서 서브도메인 생성
서브도메인 설정 및 디렉토리 구성

cPanel 접속 및 서브도메인 생성

  1. cPanel 로그인: yourdomain.com/cpanel 또는 yourdomain.com:2083 접속
  2. 도메인 섹션에서 "Domains" 또는 "서브도메인" 클릭
  3. 새 도메인 생성:
    • 도메인: members.yourdomain.com
    • 문서 루트: /home/계정명/public_html/members (자동 설정됨)
  4. 생성 버튼 클릭
서브도메인 이름 추천: members, premium, club, vip 등 멤버십 성격에 맞는 이름을 선택하세요.

SSL 인증서 설정

  1. cPanel > SSL/TLS Status 또는 Let's Encrypt
  2. members.yourdomain.com에 대해 SSL 발급
  3. 자동 갱신 활성화 확인

MySQL 데이터베이스 생성

  1. cPanel > MySQL Databases
  2. 새 데이터베이스 생성: 계정_members_wp
  3. 새 사용자 생성 (강력한 비밀번호 사용)
  4. 사용자를 데이터베이스에 추가 (모든 권한 부여)
# 생성할 정보 메모해두기 데이터베이스명: 계정_members_wp DB 사용자명: 계정_wp_user DB 비밀번호: (생성한 비밀번호) DB 호스트: localhost

방법 1: 드립 콘텐츠 (Drip Content)

회원 가입일 기준으로 매일/매주 새로운 콘텐츠를 순차적으로 공개하는 방식입니다.

회원 가입
→
Day 1
콘텐츠 공개
→
Day 2
다음 콘텐츠
→
Day 3
다음 콘텐츠
→
계속...
MemberPress의 Drip Content 기능 또는 LearnDash의 Drip-Feed Lessons을 사용하면 코딩 없이 설정 가능합니다.

방법 2: 예약 게시 (Scheduled Posts)

미리 작성해둔 글을 날짜별로 자동 게시합니다.

  1. 글 작성 시 "즉시 발행" 대신 "예약" 선택
  2. 발행 날짜와 시간 설정 (매일 오전 9시 등)
  3. 한 달치를 미리 작성해 예약 가능

방법 3: 자동 포스팅 커스텀 코드

아래 코드를 functions.php에 추가하면 매일 자동으로 새 페이지를 생성합니다.

// functions.php에 추가 - 매일 자동 페이지 생성 // 1. 커스텀 크론 스케줄 등록 add_action('wp', 'setup_daily_content_schedule'); function setup_daily_content_schedule() { if (!wp_next_scheduled('create_daily_content')) { wp_schedule_event( strtotime('today 09:00'), 'daily', 'create_daily_content' ); } } // 2. 매일 실행될 함수 add_action('create_daily_content', 'generate_daily_page'); function generate_daily_page() { $today = date('Y-m-d'); $title = date('Y년 m월 d일') . ' 오늘의 콘텐츠'; // 중복 방지 $existing = get_posts([ 'post_type' => 'post', 'meta_key' => 'daily_date', 'meta_value' => $today, ]); if (!empty($existing)) return; // 새 글 생성 $post_id = wp_insert_post([ 'post_title' => $title, 'post_content' => '오늘의 콘텐츠 내용을 여기에...', 'post_status' => 'publish', 'post_type' => 'post', 'post_author' => 1, 'post_category' => [get_cat_ID('Daily')], ]); if ($post_id) { update_post_meta($post_id, 'daily_date', $today); update_post_meta($post_id, '_membership_access', 'premium'); } }

방법 4: 외부 콘텐츠 자동 연동 (RSS/API)

// 외부 API에서 콘텐츠 가져와서 자동 게시 add_action('create_daily_content', 'fetch_and_create_content'); function fetch_and_create_content() { // 외부 API 호출 (예: 뉴스, 데이터 등) $response = wp_remote_get('https://api.example.com/daily-content'); if (is_wp_error($response)) return; $data = json_decode(wp_remote_retrieve_body($response), true); wp_insert_post([ 'post_title' => sanitize_text_field($data['title']), 'post_content' => wp_kses_post($data['content']), 'post_status' => 'publish', ]); }

cPanel Cron Job 설정 (WP-Cron 대체)

WP-Cron은 사이트 방문 시에만 실행됩니다. 방문자가 적을 때도 정확히 실행하려면 cPanel Cron Job을 설정하세요.
# 1. wp-config.php에 WP-Cron 비활성화 추가 define('DISABLE_WP_CRON', true); # 2. cPanel > Cron Jobs에서 설정 # 매 15분마다 실행 (매일 크론이 정확히 동작하도록) */15 * * * * /usr/local/bin/php /home/계정명/public_html/members/wp-cron.php # 또는 curl 사용 */15 * * * * curl -s https://members.yourdomain.com/wp-cron.php > /dev/null 2>&1

커스텀 콘텐츠 제한 코드

// 멤버십 등급별 콘텐츠 접근 제어 function restrict_content_by_membership($content) { global $post; $required = get_post_meta($post->ID, '_membership_access', true); if (!$required) return $content; if (!is_user_logged_in()) { return '<div class="membership-gate"> <h3>회원 전용 콘텐츠입니다</h3> <p>이 콘텐츠를 보려면 로그인하세요.</p> <a href="' . wp_login_url(get_permalink()) . '">로그인</a> | <a href="/membership">멤버십 가입</a> </div>'; } $user = wp_get_current_user(); $level = get_user_meta($user->ID, 'membership_level', true); $hierarchy = ['free' => 0, 'basic' => 1, 'premium' => 2, 'vip' => 3]; if (($hierarchy[$level] ?? 0) < ($hierarchy[$required] ?? 0)) { return '<div class="membership-gate"> <h3>상위 멤버십이 필요합니다</h3> <p>이 콘텐츠는 ' . $required . ' 등급 이상 회원만 볼 수 있습니다.</p> <a href="/membership">멤버십 업그레이드</a> </div>'; } return $content; } add_filter('the_content', 'restrict_content_by_membership');

숏코드로 부분 제한

// 글 안에서 부분적으로 콘텐츠 제한 // 사용법: [members level="premium"]프리미엄 전용 내용[/members] function members_only_shortcode($atts, $content = null) { $atts = shortcode_atts(['level' => 'basic'], $atts); if (!is_user_logged_in()) { return '<p>[회원 전용 콘텐츠 - 로그인 필요]</p>'; } $user_level = get_user_meta( get_current_user_id(), 'membership_level', true ); $hierarchy = ['free' => 0, 'basic' => 1, 'premium' => 2, 'vip' => 3]; if (($hierarchy[$user_level] ?? 0) >= ($hierarchy[$atts['level']] ?? 0)) { return do_shortcode($content); } return '<p>[' . $atts['level'] . ' 등급 이상 전용]</p>'; } add_shortcode('members', 'members_only_shortcode');
